# User guide

Step-by-step notes for researchers using Lattice Scout.

- [Getting started](getting-started.md): sign in, find yourself, choose your records, set your privacy choices.
- [Your private vault](vault.md): upload grants, proposals and results, see what Scout finds, and delete them.
- [Find opportunities](find-opportunities.md): what a run does, what "verified" means, why an idea may not appear, and how to save or dismiss ideas.

More pages arrive with each feature and are finished in milestone M8.
