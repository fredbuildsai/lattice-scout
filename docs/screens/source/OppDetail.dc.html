Flexible polyurethane foams are made almost entirely from petroleum polyols. We recently showed that lignin type and content set foaming dynamics and final properties (Zou et al., 2026), and new data on 48 foams show that selected lignins keep compression set within seating specifications (unpublished, Fig. 1). This project asks whether these foams can also pass flammability standards without halogenated additives…
