# M1.B2 + B4 + B5: identity, profile claim, import (design)

**Goal (plan M1 tasks 2, 4, 5).** `identity`: `Account` aggregate, `EnsureAccount` on the first authenticated call, `GET /me`, `PATCH /me/consent`. `profile`: `Researcher`, `ClaimedWork`; `FindAuthorCandidates` (name + optional affiliation, split profiles grouped by shared ORCID or institution), `ClaimProfile` (one or more author ids -> enqueue `profile.import`), `ImportProfile` job (works, topics, institution, country), `ToggleWork`. Endpoints `GET /profile/candidates`, `POST /profile/claim`, `GET /profile`, `PATCH /profile/works/{id}`.
**Acceptance.** A new user signs in (dev auth), finds "Johan Foster", sees the UBC profile with 159 works, merges the split record that shares ORCID `0000-0002-4103-8510`, and lands on Home with the profile saved. Plus: import-linter green, mypy strict on the new domain/application/ports, every new port has a fake in `tests/fakes/`.

## 1. Shared pieces
- `AccountId = NewType("AccountId", UUID)` moves to `scout/shared/ids.py` (every context refers to owners; the profile domain may not import the identity domain). `ResearcherId`, `ClaimedWorkId` live in `profile/domain`.
- `scout/ports/audit.py`: `AuditEntry(BaseModel, frozen)`: `id: UUID, actor_id: UUID | None, action: str, target: str | None, at: AwareDatetime, meta: dict[str, JsonValue]`; `class AuditLog(Protocol): async def add(self, e: AuditEntry) -> None`. Written **inside** the caller's UoW (same transaction). Actions in M1: `account.created`, `consent.changed`, `profile.claimed`, `profile.claim_conflict`.
- Events (D10 resolved here): use cases call `pull_events()` after mutating and map events to audit entries in the same UoW. No bus. Cross-context reads go through application services (the `/me` router composes identity + profile).
- `Container` gains `literature: LiteraturePort` (`_select_literature`: `fixtures` -> `FixtureLiterature(resolve_path(literature_fixtures_dir))`; `openalex` -> `OpenAlexClient(httpx.AsyncClient(timeout=20), ..., cache=PostgresOpenAlexCache(db, clock))`, added to `_lifecycles`) and `job_queue: JobQueuePort` (`PostgresJobQueue(db, clock, ids, lease_seconds=...)`; the worker reuses it). `build_handlers(c: Container, queue)` replaces `build_handlers(db, clock, queue)`.

## 2. Identity context
**Domain** `identity/domain/account.py` (dataclass, `AggregateRoot`): `id: AccountId, email: str, consent_matching: bool, consent_vault_signals: bool, launch_field: str, role: AccountRole (StrEnum user|admin), created_at, updated_at, deleted_at: datetime | None`.
- `Account.create(id, email, launch_field, now)` -> both consents False, records `AccountCreated(account_id, email_domain)`.
- `set_consent(*, matching: bool | None, vault_signals: bool | None, now)`: `matching=False` forces `vault_signals=False`; `vault_signals=True` with matching False (after applying `matching`) raises `ConsentRequiresMatching(InvariantViolation, code="consent_requires_matching")`. Records one `ConsentChanged(account_id, consent: Literal["matching","vault_signals"], value: bool)` per flag that actually changed; no change -> no event, `updated_at` untouched.
- `sync_email(email, now)` (Supabase allows email change). `ensure_active()` raises `AccountDeleted(Forbidden, code="account_deleted")` if `deleted_at`.
**Ports** `identity/ports/repos.py`: `AccountRepo`: `get(id) -> Account | None`, `add_if_absent(a) -> bool` (INSERT ... ON CONFLICT (id) DO NOTHING; unique email of another id -> `Conflict(code="email_in_use")`), `save(a)`. `IdentityUnitOfWork(UnitOfWork, Protocol)`: `accounts: AccountRepo`, `audit: AuditLog`.
**Application** `IdentityService(uow: Callable[[], IdentityUnitOfWork], clock, ids, launch_field: str)`:
- `ensure_account(sub: UUID, email: str | None) -> Account`: missing email -> `Unauthenticated(code="email_required")`. Read; if absent create + `add_if_absent`; if the insert lost a race, re-read and write no audit. Email differs -> `sync_email`. Then `ensure_active()`. One PK lookup per request; writes only on first call or email change.
- `get_account(id) -> Account`; `update_consent(id, matching, vault_signals) -> Account` (empty patch -> `ValidationFailed`); audit meta `{consent, from, to}`.
**API** dependency `current_account` (deps.py) = `current_principal` + `ensure_account`; every M1 endpoint uses it.
- `GET /me` -> `MeOut {account_id, email, role, launch_field, consent_matching, consent_vault_signals, created_at, researcher: ResearcherSummaryOut | null}`; `ResearcherSummaryOut {researcher_id, display_name, verified_level, import_status}` from `ProfileService.summary`.
- `PATCH /me/consent` `ConsentIn {consent_matching?: bool, consent_vault_signals?: bool}` (extra forbidden) -> `MeOut`. Errors 422 `validation_failed`, 422 `consent_requires_matching`, 403 `account_deleted`.

## 3. Profile context: domain (`profile/domain/`)
- `names.py`: `name_tokens(s) -> tuple[str, ...]` (NFKD, strip accents, casefold, drop `(...)` and digits, split on space/`.`/`-`/`,`). `names_compatible(a, b) -> bool`: both have >= 2 tokens; every token of the shorter matches a distinct token of the longer (equal, or a 1-letter token equal to the other's initial); at least one equal match of length >= 2. Order-insensitive ("Foster E. Johan" ~ "Earl Johan Foster").
- `grouping.py`: `AuthorSnapshot` (frozen pydantic; `id, display_name, orcid: str | None, works_count, cited_by_count, institutions: tuple[str, ...], country, topics: tuple[TopicWeight, ...]`), `TopicWeight(id, name, subfield, weight: float in [0,1])`, `RecordBasis(StrEnum): primary | orcid | institution_name | manual`, `GroupedRecord(snapshot, basis)`, `CandidateGroup(primary, records: tuple[GroupedRecord, ...], possible: tuple[GroupedRecord, ...])` with `includes_records = len(records)`, `works_count = sum(records)`, `cited_by_count = sum`, `orcid`, `institutions` (ordered union), `top_topics(n=5)` (weights summed over records, renormalised).
  `group_candidates(snaps, affiliation_hint) -> list[CandidateGroup]`: (1) dedupe by id, first occurrence wins, institutions unioned; (2) union records with equal non-null ORCID; primary = max `works_count`, then has institutions, then id; (3) each **ORCID-less singleton** that shares a casefolded institution with an ORCID group and is `names_compatible` with one of its records becomes `possible` (basis `institution_name`) of the largest such group (tie: id). Weak links never chain and never merge; a record with an ORCID never joins another ORCID's group; (4) remaining records are singleton groups; (5) order: affiliation-hint match first, then `works_count` desc, then primary id. Pure and deterministic.
  Fixtures: group 1 = records `A5059588273` (primary, 159) + `A5140167166` (orcid, 1), possible `A5138740368`, `A5158972402` (UBC, no ORCID); then singletons `A5003854624`, `A5030450974`, `A5085584773`.
- `researcher.py`: `ImportStatus(StrEnum) queued|importing|done|failed`; `VerifiedLevel(StrEnum) self_claimed|orcid_matched|contested`; `ResearcherOpenAlexId(author_id: str, merged: bool, basis: RecordBasis, display_name, orcid, works_count, imported_generation: int | None)`; `Researcher(AggregateRoot)`: `id, account_id: AccountId, display_name, orcid, institution, country, career_stage: str | None, verified_level, openalex_ids: list[ResearcherOpenAlexId], topics: list[ResearcherTopic], import_status, import_generation: int, import_error: str | None, import_requested_at, imported_at, created_at, updated_at`.
  `Researcher.claim(id, account_id, records, primary_id, now)` / `reclaim(records, primary_id, now)`: primary first with `merged=False`, others `merged=True`; basis `orcid` if same ORCID as primary, `institution_name` if no ORCID + shared institution + compatible name, else `manual`; two different non-null ORCIDs -> `ConflictingOrcids(InvariantViolation)`. Bumps `import_generation`, `import_status=queued`, records `ProfileClaimed(researcher_id, account_id, author_ids, generation)`. `recompute_verification(contested: bool)`: contested wins; else `orcid_matched` iff primary has ORCID and all bases in {primary, orcid}; else `self_claimed`. `start_import(gen)`, `finish_import(gen, topics, institution, country, now)`, `fail_import(gen, code, now)` ignore a stale `gen` (return False).
- `work.py`: `UncertainReason(StrEnum) non_article_type|name_mismatch`; `ClaimedWork(id, researcher_id, openalex_work_id, doi, title, year, cited_by, type, abstract, topics: tuple[TopicWeight, ...], source_author_ids: frozenset[str], included: bool, included_by_user: bool, uncertain_reason)`. `initial_inclusion(work_type, names_at_claimed_positions, variants) -> UncertainReason | None`: type not in {article, review} -> `non_article_type`; else if any name is present and none is compatible with a variant (display names of all claimed records) -> `name_mismatch`; absent names (truncated authorships) never penalise. `toggle(included)` sets `included_by_user=True`. `refresh(record, author_id, reason)` updates metadata and adds the source id; recomputes `included` only when `not included_by_user`.
- `topics.py`: `compute_topics(works, max_topics=25) -> list[ResearcherTopic(topic_id, name, subfield, weight)]`: sum of topic scores (missing score = 1.0) over **included** works, divided by the max, sorted by weight desc then id.

## 4. Profile context: ports, application, job
**Ports** `profile/ports/repos.py`: `ResearcherRepo`: `get_by_account(account_id) -> Researcher | None`, `find_by_author_ids(ids: Collection[str]) -> list[Researcher]`, `add(r)`, `save(r)` (replaces child rows openalex_ids/topics). `ClaimedWorkRepo`: `list_for(researcher_id) -> list[ClaimedWork]`, `get(work_id, researcher_id) -> ClaimedWork | None`, `upsert_many(works)` (on `(researcher_id, openalex_work_id)`), `delete_unsourced(researcher_id, keep_author_ids) -> int` (drops ids not claimed any more, deletes rows left with none). `ProfileUnitOfWork`: `researchers`, `works`, `audit`.
**`ProfileService`**`(uow, literature, jobs: JobQueuePort, clock, ids, cfg: ProfileConfig(max_groups=10, enrich_groups=3, max_claim_ids=10, works_limit=500, max_topics=25))`:
- `find_candidates(name, affiliation) -> list[CandidateGroup]`: name stripped, 2..200 chars else `ValidationFailed`. Calls: `search_authors` (1), `authors_by_orcid` for distinct ORCIDs in the first `enrich_groups` hits (<= 3), map to `AuthorSnapshot`, `group_candidates`, then `get_author(primary)` for the first 3 groups whose topics are empty (search hits carry none). <= 7 OpenAlex calls, all cached. No DB access, no claimant info (does not reveal other users).
- `claim(account_id, author_ids, primary_author_id | None, session_id) -> Researcher`: 1..10 ids, normalised with `short_id`, `^A\d+$`, deduped, primary in the list (default first) else `ValidationFailed`. `get_author` per id **before** opening the UoW (unknown -> 422 `unknown_author`, `extra={"author_id"}`). In one UoW: create or `reclaim`; **idempotent**: same id set + same primary and status `queued|importing|done` -> no bump, return as is (re-enqueue if queued); `failed` or a different set -> bump. Then `find_by_author_ids(old ∪ new ids)`; every researcher sharing an id with another account -> `recompute_verification(contested=True)`, audit `profile.claim_conflict` (`meta: {author_ids, other_researcher_ids}`); others recomputed. Audit `profile.claimed`. Commit, then `jobs.enqueue(JobSpec(kind="profile.import", payload={account_id, session_id, feature: "profile.import", researcher_id, generation}, dedupe_key=f"{researcher_id}:{generation}", max_attempts=5))`. Enqueue failure -> 503; the client re-POSTs and gets the same generation (idempotent), so no stuck "queued" profile.
- `get_profile(account_id) -> ProfileView(researcher, works)` (404 `profile_not_found`), `summary(account_id) -> Researcher | None`, `toggle_work(account_id, work_id, included) -> ClaimedWork`: researcher by account, work by `(work_id, researcher.id)`, else `NotFound` (never 403); recompute topics; one UoW.
**`ImportProfile.handle(payload, *, last_attempt: bool) -> dict`** (job `profile.import`, at-least-once, resumable):
1. Load the researcher; missing or `generation != import_generation` or status `done` -> `{"skipped": reason}`. `start_import` + commit.
2. For each claimed id (primary first) with `imported_generation != gen`: `list_author_works(id, works_limit)` outside any UoW, then one UoW: map to `ClaimedWork` (new rows: `included = initial_inclusion(...) is None`), `upsert_many`, set `imported_generation = gen`, commit. That per-author checkpoint makes the job resumable after a crash.
3. One UoW: `delete_unsourced`, `compute_topics`, institution = primary's `institutions[0]`, country = primary's; `finish_import`; commit. Returns `{works, included, authors}`.
`InfrastructureError`/any error re-raises (worker back-off); if `last_attempt`, first `fail_import(gen, "import_failed")` in its own UoW. A `NotFound` author during import is skipped and logged. Bootstrap wires `profile.import` -> `import_profile(c).handle(Job.payload, last_attempt=job.attempts >= job.max_attempts)`.

## 5. Endpoints (`scout/api/profile.py`, DTOs in `api/schemas/profile.py`; all use `current_account`)
| Endpoint | Request | Response | Errors |
|---|---|---|---|

## 7. Invariants (tests assert)
1. `consent_vault_signals => consent_matching` after any sequence of `set_consent`; events = number of real flag changes.
2. `ensure_account` twice (also concurrently on Postgres) -> one row, one `account.created` audit row.
3. Grouping: each input id appears exactly once across all `records`/`possible`; `records` of a group share one ORCID or the group is a singleton; a record with ORCID X is never in a group with ORCID Y; `possible` records have no ORCID, share an institution and a compatible name; `works_count == sum(records)`; result invariant under input permutation.
4. `names_compatible` symmetric, case/accent/order-insensitive; one-token names are never compatible.
5. A claim with two different ORCIDs fails; one researcher per account; an author id claimed by two accounts makes both `contested`; the other user is never revealed by any endpoint.
6. Import: running twice gives the same rows; a crash after author 1 resumes without duplicates; a stale generation is a no-op; user toggles survive re-import; excluded works never count towards topics; topic weights in [0,1] with max 1.
7. Researcher data only for its owner: `GET /profile` and `PATCH /profile/works/{id}` of user B on A's work -> 404.

## 10. Risks
- The profile domain cannot import `scout.ports.literature`: map `AuthorRecord`/`WorkRecord` to domain snapshots in the application layer.
- OpenAlex calls must stay outside open UoWs (no DB transaction held during HTTP).
- Truncated authorships (Moreira) must not be marked `name_mismatch`.
- `contested` can be triggered by an impostor against a real user: admin resolution comes in M7; matching (M5) must skip `contested` researchers.
