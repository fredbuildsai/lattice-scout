# ADR 011: Unverified claims are persisted, never shown

- **Status:** accepted
- **Date:** 2026-10-20 (from the hand-off architecture)

## Context
See [ARCHITECTURE.md](../ARCHITECTURE.md) §15 and the decision register §0.1.

## Decision
Unverified claims are persisted, never shown

## Consequences
Lets us analyse failure modes and improve prompts; users only see verified claims with inline sources.
