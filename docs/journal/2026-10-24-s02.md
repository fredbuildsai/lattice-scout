## Problems and solutions
| Problem | Cause | Solution |
|---|---|---|
| Matches e2e: "We could not load your account" for the seeded users | `seed_dev.py` used fixed account ids; dev login derives the id from the e-mail, so the same e-mail meant a different id (EmailInUse) | Seed accounts use `DevTokenIssuer.sub_for(email)` (DECISIONS 118) |
| Reveal job: `JointIdeas: unavailable` for the demo pair | The idea input listed methods in database row order; the fixture was made with weight order | `_side` sorts methods by weight then id |
| Joint ideas never appeared on the page | `GET /matches` was not refetched after the reveal job | `refetchInterval` while a revealed match has pending ideas |
| `check()` failed on the weekly switch | The checkbox is optimistic and React re-renders after the click | Use `click()` then `toBeChecked()` |
| Pause banner never seen | The test looked for "paused", the message says "daily analysis limit" | Match the real text; `cost_usd` is `numeric(12,8)`, so the seeded row costs 9000 |
| Card equality after a deletion failed in the scan test | Seed rationale carried refs of the deleted user in the survivor's list | `without()` clears every ref, texts stay |
| `pkill -f` ended the shell | The pattern matched the command line of the shell itself | `ps` piped to `grep -E` with a bracket in the pattern |
